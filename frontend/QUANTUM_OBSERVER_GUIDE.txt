🎯 WHAT IS IT?
Elements only animate when you're looking at them (cursor near or in viewport).
This REDUCES LAG because only observed elements animate!

📱 DEVICE SUPPORT:
✅ Desktop (mouse tracking)
✅ Mobile (touch tracking)
✅ iOS (touch tracking)
✅ Android (touch tracking)
✅ Tablets (touch tracking)
✅ Auto-adapts particle count based on device performance

🚀 FEATURES:

1. QUANTUM PARTICLES
   - Follow your cursor/touch with physics
   - Adaptive count based on device (2-15 particles)
   - Trails and glow effects
   - Auto-pauses when tab not visible

2. PROXIMITY DETECTION
   - Elements detect when cursor is near
   - Configurable radius (default: 200px desktop, 150px mobile)
   - Works with touch on mobile

3. VIEWPORT DETECTION
   - Elements detect when they're visible on screen
   - Uses Intersection Observer (super performant)

4. COMBINED MODE
   - Both proximity AND viewport detection
   - Element must be visible AND cursor near

💡 HOW TO USE:

METHOD 1: React Hook (Easiest)
```javascript
import useQuantumObserver from '../hooks/useQuantumObserver'

function MyComponent() {
  const ref = useQuantumObserver({
    type: 'both',        // 'proximity', 'viewport', or 'both'
    radius: 200,         // Distance threshold
    onObserve: (el) => console.log('Observed!'),
    onUnobserve: (el) => console.log('Unobserved!')
  })
  
  return (
    <div ref={ref} className="quantum-pulse">
      This pulses when you look at it!
    </div>
  )
}
```

METHOD 2: Direct API
```javascript
import quantumObserver from '../utils/quantumObserver'

const element = document.querySelector('.my-element')
quantumObserver.observe(element, {
  type: 'proximity',
  radius: 150
})
```
