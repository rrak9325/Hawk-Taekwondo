✨ ANIMATION CLASSES YOU CAN USE:

1. FADE IN ANIMATIONS:
   .animate-fade-in-up      - Fades in from bottom (smooth)
   .animate-fade-in-left    - Slides in from left
   .animate-fade-in-right   - Slides in from right
   .animate-scale-in        - Scales up smoothly

2. CONTINUOUS ANIMATIONS:
   .animate-subtle-float    - Gentle floating motion
   .animate-glow-pulse      - Smooth glow effect
   .animate-shimmer         - Shimmer/shine effect

3. HOVER EFFECTS:
   .hover-lift              - Lifts up on hover with shadow
   .hover-glow              - Glows on hover
   .hover-scale             - Scales up slightly on hover

4. SCROLL REVEAL:
   .scroll-reveal           - Elements fade in as you scroll to them
   
   Usage with hook:
   import useScrollReveal from '../hooks/useScrollReveal'
   
   const MyComponent = () => {
     const ref = useScrollReveal()
     return <div ref={ref} className="scroll-reveal">Content</div>
   }

5. STAGGER DELAYS (for sequential animations):
   .stagger-1 through .stagger-6
   
   Example:
   <div className="animate-fade-in-up stagger-1">First</div>
   <div className="animate-fade-in-up stagger-2">Second</div>
   <div className="animate-fade-in-up stagger-3">Third</div>

6. SMOOTH TRANSITIONS:
   .transition-smooth       - 0.3s smooth transition
   .transition-smooth-slow  - 0.5s smooth transition
